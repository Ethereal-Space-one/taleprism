# 0.9.2: a judgment is not a playback receipt

The acceptance inputs are four named public readers, two public editable archives, four source-bound worksheets and one worksheet using the historical Chibi editable plate IDs. The extra worksheet does **not** represent a fifth story or twelve extra illustrations. Rebuilding the six books must yield the exact ZIP hashes recorded for 0.9.1 in the [prior release checksums](https://github.com/Ethereal-Space-one/taleprism/releases/download/v0.9.1/SHA256SUMS).

1. **Inventory the actual books.** Bind each of 17 narrative plates to validated UTF-8 text, its paragraph position, and the actual image bytes and dimensions. A cover, map or portrait is not an extra plate. Check the source quotation and five non-empty editorial fields. A change of image, source or position must not silently inherit approval.
2. **Observe the final exports.** In an offline Chromium run, visit the real plates under ordinary reading and system reduced motion. The three existing local effects should produce changing frames under ordinary reading and none under reduced motion. The 12 still and two deferred decisions should produce no motion. Pixel activity is not artistic acceptance: the first Chibi wave still overlaps part of a foreground pine branch.
3. **Restore and sign off.** Import both final editable archives into separate empty stores. Confirm they start unassessed, reject wrong image bindings, and require explicit consent to adopt a matching worksheet. Test the workbench through upload, placement, draft export, screening, sign-off and later change. A worksheet must not leak into either exported format.
4. **Protect the reader.** Run the [edition contract](VALIDATION-v0.9.1.md) on the four final readers and two ordinary editable re-exports: source, images, plate descriptions, reveal timing, sound and progress. The historical same-origin upgrade test explicitly starts at v0.9.0; byte identity with v0.9.1 separately proves no newer reader-code or data migration.
5. **Bind evidence to the release.** The finalizer refuses stale, partial or static-only receipts; the plate receipt binds the commit, current catalog, reader archives, worksheets and cold-restored projects. Compare all expected hashes, including shipped downloads; internal evidence files are not extra release attachments. See [rebuild commands](RELEASING.md).

这些检查不能代替整幅遮挡和艺术复核、真人听评、Safari／物理手机测试或真实模型服务测试。源代码与 GitHub 附件、Pages 部署和线上验收是不同步骤。示例没有新增动效，没有更改图解或在线制作界面。

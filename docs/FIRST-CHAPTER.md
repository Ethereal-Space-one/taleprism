# 自己的第一章 · Your first chapter

**给读者的是解压后可双击打开的作品，不是一个工程，也不是提示词。** 制作台已安装时，无需 AI 账号、出图工具或付费服务。若从 GitHub 下载的是 Agent 入门包，它只包含创作手顺，不是制作台；[安装本地制作台](快速上手.md#安装与打开)。下面的步骤针对包含「段落试演与防剧透校对」的制作台版本。

1. 打开首页 → **用自己的图文开始**。带一章你有权分享的文字，粘贴或导入 TXT，明确选择权利状态。不要拿示例冒充自己的作品。
2. 在「这次想做什么？」勾选插图、朗读或声景，可多选。按勾选顺序打开第一项；只引导路径，不生成或采用素材。全不选就点 **只保留原文，直接试读与导出**。第一稿不是空白模板，已是保留原句的可读章节。如果还没图，此时就能分享。
3. 打开 **段落试演与防剧透校对**。选定一段，不换原句，对比留白、声音和局部动效。声景优先播放本段已采用版本；没有时只提供标明为样音的细雨。可从此处进入相同段落的声景编辑：选依据，生成候选，完整试听后再决定采用。试演留白不会删除已有声景。局部动效只在绑定底图和阅读器支持并复核的配方齐备时启用。没有插图或没有通过复核时会明确说明，不用另一张图代替。
4. 在同一个校样里，切换 **进入所选段落前 / 读完所选段落时**。先在「卷首校样」把章名、副标题和封面图一起读（两种位置都可见），再对照前后摘录、当时已经解锁的画卷和图说，听刚读过的一段。封面校样展示原图，实际裁切请以导出的读本为准。可输入一个本不该出现的名字，检查截至此处的逐字匹配；无命中不等于没有剧透。图像、隐喻和录音的叙事含义都由作者判断，不自动改字、放行或撤下。
5. **导出独立阅读器 → 下载阅读器**。把整个 ZIP 交给另一人，对方**完整解压 → 打开 index.html → 开始阅读**；不是在 ZIP 预览窗口内双击单个文件。导出的读本不包含编辑校样、试听样音或未采用的声音。**下载工程 ZIP** 是可继续编辑的备份，可能包含私人素材，不要当作公开读本转发。

**卷首怎么审？** 同一张黄雨衣背影，配《末班灯》只给一个线索；配《小满回来了》，读者更容易把画中人与“小满归来”连起来。若本章本来就要先交代归来、把悬念留给“为什么回来”，这种预告是有意的。先决定哪些信息要在卷首给出、哪些留到正文，再调标题、画面或两者。工具不自动判剧透。

### 十分钟门槛：用没见过制作台的人来测

准备：制作台已就绪、一个空白项目空间、一篇未导入且获授权的原文。冷安装和依赖下载时间另外记录；不把朋友等待收件的时间算作打开读本的操作时间。不给教程以外的口头提示。

| 观察点 | 记下什么 |
| --- | --- |
| 打开空白首页时启动计时 | 版本、系统、语言、章节长度；哪一步需要找帮助 |
| 能区分试演与采用、读本与工程 | 参与者亲口说明会把哪个文件发出去；试演前后作品不应改变 |
| 在新目录、断网打开分享包 | 正文逐字保留；读到指定段落；未选的声音不响 |
| 收件人看到第一段时停止计时 | 整体不超过 10 分钟为本轮目标。记录实际时间、失败或求助点，不代填 |

自动回归 `tools/check_studio_browser.py` 用全新浏览器与临时项目执行上述操作，记录浏览器计时、文本字节及离线请求。**脚本不是首次用户，实测时间不能冒充真人用时。**

## In English

With the local workbench installed, choose **Start with your own text and image** on the home screen (用自己的图文开始). Import an authorized TXT or paste a chapter, select rights, then choose any combination of illustration, narration and ambience, or leave all unchecked and choose **text only, preview and export**. Choices only guide which editor opens first; nothing is generated or adopted. The Agent Starter is a prompt kit, not the workbench.

Use the passage proof desk to compare the same paragraph in quiet, with a soundscape, or with a supported local motion. The rain reference is labeled; it is never adopted by auditioning. Motion requires a placed image and a valid reviewed direction. A read-position proof shows the title, subtitle and cover together before any text, then the last reached excerpt, unlocked artwork and captions, and audio. Check actual cover cropping in the exported reader; an optional exact-phrase check cannot judge the meaning of images, recordings or paraphrases.

Export and download the **standalone reader**, not the editable project. Share the whole archive. The recipient extracts all files, opens `index.html`, and selects Start Reading. For a real first-use trial, start the ten-minute clock on the home page with the workbench already installed and stop at the first passage in an independently unpacked copy. Record help needed and elapsed time. Browser timings are not human timings.

**Review the opening as a whole.** The same yellow raincoat is an unnamed clue under *Last Light*, but *Xiao Man Returns* invites the reader to identify the figure and infer the return. If the chapter intentionally opens with the return and saves the reason for later, that is a deliberate preview. Decide what the reader should know before line one; the workbench does not judge spoilers for you.

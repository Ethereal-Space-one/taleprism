# Taleprism v0.3.2 Public Preview / 点开就读

- 在线阅读：继续使用原有《赤壁》入口 `/taleprism/`，部署后核对网页与本版 Release 的相同内容。
- 离线阅读：macOS 解压独立阅读包后使用包内启动器。需已安装 Python 3；只在本机提供阅读，不对其他设备开放。
- 防剧透：《赤壁》全章画卷在显示后文插图或标题前提示；保留主动浏览全章的选择。
- 制作：八模板独立版本提升到 0.2.1，补充画面要传递的阅读线索和不提前揭示的内容；既有项目格式不变。

本版不纳入《黄盖出船》青旗候选、拦船灰度分镜、纯文／单图 A/B 验收包或私有作品。公开示例原文、已发布图像和既有标签保持不变。

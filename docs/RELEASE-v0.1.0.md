# Taleprism v0.1.0 · Public Preview

Taleprism turns fiction into illustrated reading experiences while preserving its original text. This first trial opens the prompt workflow and the local workbench developed through the Last Light and Chibi iterations.

## Start here

- [Read Chibi online](https://ethereal-space-one.github.io/taleprism/).
- [Use the eight templates](https://github.com/Ethereal-Space-one/taleprism/tree/v0.1.0/prompts) with your chosen AI tools, or download the prompt starter below.
- [Install the local workbench](https://github.com/Ethereal-Space-one/taleprism/tree/v0.1.0#readme) and import the Last Light project.
- [Complete English walkthrough](https://github.com/Ethereal-Space-one/taleprism/blob/v0.1.0/examples/last-light/README.en.md).

The workflow covers exact source evidence, each person's goals and visible acting, scene masters, prop states, image inspection and targeted repairs. The Last Light tutorial includes actual bench/basket failures and their correction instructions. Generated documents and the workbench share the same versioned rules.

## Which file?

| Attachment | Purpose |
| --- | --- |
| `taleprism-v0.1.0-prompt-starter.zip` | Templates, tutorial, source and reference images; no app installation |
| `taleprism-v0.1.0-last-light-project.zip` | Editable project; import in the workbench |
| `taleprism-v0.1.0-chibi-reader.zip` | Chibi public showcase: 12 scene illustrations, eight characters, nine portraits and three map stages |
| `taleprism-v0.1.0-last-light-reader.zip` | Independent reading website; extract, verify and serve over HTTP |
| `SHA256SUMS`, `release-manifest.json` | Download integrity, sizes, commit and validation scope |
| `CHIBI-SHA256SUMS`, `chibi-demo-manifest.json` | Integrity and inspection scope of the added Chibi reader |
| GitHub Source code | Lightweight application source and tutorial references; project ZIP downloads separately |

Public samples do not include macOS-generated demonstration audio. Existing local projects are not altered. Legacy `storygal` module, environment variables, project formats and browser progress keys remain compatible.

## Trial boundaries

The workbench UI is Chinese. Native Windows startup is not supported. The visual example validates a fixed camera with human/assistant inspection; it does not guarantee arbitrary viewpoints or pixel-perfect continuity. The OpenAI voice adapter is prepared but has not been live-validated. Third-party AI tools may require accounts and payment.

Final creator art approval and independent external-user onboarding remain pending. Assistant checks are labelled accordingly. The [validation record](https://github.com/Ethereal-Space-one/taleprism/blob/v0.1.0/docs/VALIDATION-v0.1.0.md) distinguishes actual software checks from these limits.

Report the exact step or visual issue through [Issues](https://github.com/Ethereal-Space-one/taleprism/issues/new/choose). Do not send API keys; source excerpts and images are optional. Code and prompts are MIT; content retains its provenance notices.

# Taleprism 0.9.0 · Public preview

**Try the reading experience:** open the [GitHub prerelease](https://github.com/Ethereal-Space-one/taleprism/releases/tag/v0.9.0), download either of the following reader ZIPs, extract it fully and open **index.html**. No server, app, API key or network connection is needed for reading.
- **The Door Left Open · 留门**: a brief passing car and rain meet the wet roadway; the boots and threshold do not move.
- **The Margin · 留白处**: a picture stays still; an earlier sentence folds back into a later paragraph and pencil strokes sound only near the end.

Readers can pause the whole performance, mute sound independently, or choose Quiet reading before opening. System reduced motion keeps illustrations static. A browser may require a real click before allowing audio. There is no forced scrolling or narration autoplay.

**For making a book:** the [editable examples](../samples/content-packs/catalog.json) are Chibi and Last Light. Each has a reader and a project ZIP; only the project ZIP can be imported into the workbench. The two new demonstrations above are reader-only by design. The prompt starter and full source ZIP are distinct downloads. The author may finish without asking for an AI suggestion. Approved cues appear in their intended passages; rejected options and editing history never enter the new demonstration readers. For reproducible synthetic creative trials, see [Reading Lab](../examples/reading-lab/README.md).

The prerelease first updated the downloadable software, while Pages was still serving v0.3.2. A subsequent deployment brought the [online Chibi](https://ethereal-space-one.github.io/taleprism/) to the same v0.9.0 reader as the download. The v0.3.3 GitHub example pairs were the verified build inputs, not an intermediate Pages deployment. The GitHub release remains a prerelease.

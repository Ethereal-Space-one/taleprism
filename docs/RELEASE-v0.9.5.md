# Taleprism v0.9.5 · 交接时看清什么能带走

- **备份前看审图范围。**「备份可编辑工程」列出本版哪些动静判断可随私有审图单移入、哪些未审或需修正，也列出恢复后须重新核对的出场时机。私有 JSON 单独下载；工程 ZIP 和读本仍不带出场时机意见。
- **选错包，知道怎么回来。** 把阅读器 ZIP 误选为可编辑工程时，原有验证照常拒绝，界面提示改选可编辑备份，示例作品则选解压后的 `Project.zip`。
- **手动听到一半，切换自动演绎不再打断。** v0.9.5 工作台新导出的读本保留手动声景、朗读或对白的播放。全局静音、停止和重播照常工作。

首章从 [AI 创作入门包](https://github.com/Ethereal-Space-one/taleprism/releases/download/v0.9.5/taleprism-agent-starter.zip) 开始；安装用 [制作台源码包](https://github.com/Ethereal-Space-one/taleprism/releases/download/v0.9.5/taleprism-workbench-source.zip)。

《赤壁》《末班灯》作品包继续保留原有读本和可编辑工程，可导入新版制作台再导出。现成作品包和在线《赤壁》不会因为这次源码发布自动换读本；历史附件不替换。

## English

The backup panel shows which still/motion decisions can be imported from a separate private worksheet and how many reveal-timing decisions need a new review after restoration. Reader ZIPs are not editable backups; if you choose one, the workbench directs you to the right file without weakening archive validation.

Newly exported readers no longer interrupt manually started sound when automatic effects are toggled. Mute, stop and replay still work. This does not replace the readers in the existing Chibi and Last Light bundles or roll out the online Chibi edition.

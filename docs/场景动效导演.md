# 场景动效导演：从小说的一句话，到读者可开关的场景

动效是可选的一层，不是另一张图，也不是下一镜。它最有用的时候，是让读者看懂环境怎么影响当前瞬间。关闭时仍应该是一幅好图。不能指认接触线，或只想让画面「热闹一点」时，选静图就好。

## 用自己的图完成一次

1. 先在「章节制作方案」选定瞬间、原文段落和底图。按原有流程上传、审校、应用镜头，把这张图安排到独立阅读器的章节编排。
2. 在「独立阅读器与导出」的章节编排里，展开插图下的「场景动效导演」。在「环境动作」选雨或江岸，不先追求强度。填入当前阅读位置已经出现的逐字原文和你实际看到的画面观察。原文可以证明场景和时机；不能用来伪证原文没有写出的浪高、风向或雨量。
3. 沿当前底图边界点选，闭合并加入允许区；也可用下方百分比坐标代替点图。不要复制另一张图的坐标。人物脸、手、重要道具、照明和不能提前出现的线索，留在范围外。范围不是越大越好，先做最小的有效范围。想做涟漪就另外用「标接雨湿地（涟漪）」圈出确实接雨的地面；看不出地面就不做涟漪。江岸还要点「从左向右标岸线」并完成岸线，岸线和撞点须落在动作允许区。
4. 点「打开动效对照」，主动开启动效，把原图和一整个循环并排比较。新复核前需要可见播放至少 8 秒；这个计时不能替你判断画面是否合格。下面两种检查句可以直接拿去审片。遮罩、位置、强度或依据改过，就重新预览与复核。动效通过与底图通过是两件事。
5. 勾选复核声明，点「纳入章节草稿」，再点「保存章节编排」。还没看完可先存待复核草稿，读者仍只看静图。从插图前一段开始试读：「开始阅读」后，读到这幅画时才播放已复核动效；选择「安静阅读」则先看静图，可以放大手动试播。关闭动效后，仍是同一张原图。
6. 导出独立阅读器并从头再试一次。导出阅读包是给读者的；以后想换电脑继续编辑，请另导出「可编辑工程」，在新项目导入，不覆盖旧工程。没有用到 AI 或模型密钥。

如果阅读器只显示静图，先核对是否处于安静阅读或暂停了自动演绎、设备是否开启「减少动效」，再核对插图和原文是否改过。原画换过、依据改变或设置没有复核时，先保持静图，重新看看实际画面后再确认，不沿用旧审定。

## 两个可以复用的导演思路

**《末班灯》：斜雨落地。** 原文有「傍晚的雨斜着落进站台」。先保人物、旧灯和檐下手部动作，再认出受雨的湿地，让檐外雨线更可读；涟漪只出现在应该接水的地方。检查句：先看到雨落下，再看到一个短促的落点后果；檐下人脸、干燥的长凳和灯光一直清楚。到后文雨变小时，此镜头的雨势不应照搬。

**《赤壁》：浪打江岸。** 先看实际图能不能指认岩石接水的位置，沿实线标岸，水体、撞点和回流都以这条线为基准。浪到岸才起水花，泡沫随后往水里退。检查句：能看出「推水 → 碰岸 → 水花落下 → 泡沫回流」，而不是白线在岩上闪、没浪先喷水，或用浓雾盖掉接触线。原图里的人、船灯与远山不必跟着动。

这两个样例是审片参照，不是面向所有图片的默认配置。烟、江雾等可先用[环境动作人工简报](../prompts/optional-ambient-motion.md)的「作用、边界、保护区、四拍」规划；尚无对应制作台选项时保持静图，不把简报当成可执行配置。

## 导出前自查

- [ ] 章节从头试读，不先选「显示全章插图」；未来插图、它的动效和说明没有提前出现。
- [ ] 关闭动画、系统减少动效、缩放看大图时，原图仍稳定、完整。
- [ ] 桌面和窄屏各完整看一轮；首个可见事件来自正确的位置，尾巴收干净而非硬切。
- [ ] 可编辑工程重新导入后可以接着编辑；独立阅读器无需工作台也能读。按实际分别记「已验证」或「未检查」。

# Taleprism 制作台快速上手

只想使用提示词，直接看[模板](../prompts/README.md)与[三镜头教程](../examples/last-light/README.md)。以下用于本地完整制作台。

## 安装与打开

需要 uv、Python 3.11+、Node.js 22.12+ 与 npm。在源码目录执行 `./start.sh`；首次会下载依赖并构建界面。打开 <http://127.0.0.1:8000>。之后执行 `./run.sh`；macOS 可双击“打开Taleprism.command”在后台运行，用“停止Taleprism.command”停止。

示例工程单独下载：在[发布页](https://github.com/Ethereal-Space-one/taleprism/releases/tag/v0.1.0)取 `taleprism-v0.1.0-last-light-project.zip`。进入左侧“示例与工程”，点“导入可编辑工程”。每次导入新建项目，不覆盖原项目。没有下载包时界面会提示；不需要填写任何 AI 密钥。

在空白首页点“从《末班灯》原文练习”只会创建正文项目，便于从头练习。完整工程与原文练习不是同一个入口。

## 从已有示例理解流程

1. 导入完整工程后打开“章节制作方案”。全章风格、预算、三个镜头和固定场景已经填写。
2. 查看每个人的目标、所知、公开姿态、顾虑和可见动作。原文依据必须逐字对应所选段落；推断写在艺术解释中。
3. 展开“场景与物件设定”，看母版、布局、固定物件与道具。每个镜头都有完整物件状态和变化理由。
4. 展开镜头的连续性区域，并排查看母版、前序图和当前图。现有检查来自助手，不是用户最终艺术复核。
5. 打开“阅读预览”连续阅读；修改方案或上游图会撤销相关检查，需要重新核对后应用。

## 制作自己的短篇

导入有权使用的 TXT，选择使用范围。原始文件和工作文本只读保存，最多 30,000 字。

在“人物与审校”确认人物、别名、对白归属。上传人物参考图/立绘并接受。无需给每个配角做多套立绘；把重要的身份参照优先做好。

在“章节制作方案”设定画风和图片预算，按叙事作用添加镜头。填写具体瞬间、原文依据、镜头、环境、艺术解释与不能提前出现的内容。分别编写各人的处境与动作。

同地点先设母版和物件清单，再交代每镜头的状态。下载生图任务，把真实参考图上传到所用图片工具。文件名和资产 ID 不会自动传送图片。网页不直接调用 Codex 会话内生图。

成图在“阅读器与场景”上传、接受，然后在方案内选择图片。确认镜头方案，按时间顺序比较母版、前序和当前图；勾选检查项并写实际观察。修复发现的问题后再记录连续性检查，最后“应用已确认镜头”。

无密钥也能做以上手工流程。文本 AI 可通过“导出 AI 任务”交给自己的工具，带回 `{source_sha256, plan}`；导入后仍需审校。结构化格式见 [schemas](../schemas/README.md)。

## 可选配音与导出

公开示例不含系统演示音频。macOS 装好中文音色与 ffmpeg 后，可在“对白配音”选择少量已确认对白，设角色音色、合成、试听并接受。云端配音需自行配置账户；OpenAI 适配器真实调用仍未验证。

阅读器导出只包含可交付内容，不含个人阅读进度、密钥或制作日志。工程导出保留可编辑方案与素材；工程 ZIP 用于迁移，阅读器 ZIP 用于阅读。

阅读器解压后在该目录执行 `python3 verify_package.py`，再执行 `python3 -m http.server 8080 --bind 127.0.0.1`，打开 <http://127.0.0.1:8080>。不要直接双击 HTML。

## 常见问题

- 浏览器打不开：确认在同一台电脑启动了服务、终端没有退出，地址端口一致。后台日志在 `data/workbench.log`。
- 原始赤壁图片缺失：轻量源码不含这批大型素材。原有本机项目可继续使用；新使用者先走《末班灯》或自己的内容。
- 修改后不能应用：先保存并重新确认镜头；上游变化会使当前和后续检查失效。
- 声音不能导出：所选对白须试听接受；改音色、读音或指令会使旧声音不再匹配。
- 迁移电脑：优先导出可编辑工程再导入；完整数据备份与恢复见[恢复指南](使用与恢复指南.md)。

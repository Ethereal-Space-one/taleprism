# 不用密钥，借助外部 AI 整理角色与对白

这条流程不需要在 Taleprism 配置模型密钥，也不会替你调用、登录或发送到任何 AI 服务。原有的「AI 抽取候选」接口流程仍然可用。

1. 在「角色与对白审校」展开「不用密钥：交给外部 AI，再导回候选」，下载本章任务 JSON。
2. 自行把任务文件交给你选择的 AI。请它遵循文件中的 `instructions`，只返回填写后的 `response_template`，保存为 UTF-8 JSON。不要返回任务文件或 Markdown 代码围栏。
3. 回到同一项目，选择这一次的回复文件，点击「仅验证并导入所选文件的候选」。请先确认角色，再逐句审校说话人。导入不是身份、对白或美术的人工确认。

**分享前先检查内容与权利。** 任务文件包含本章原文、对白编号和已确认角色名称/别名。下载只保存本地文件；你自行上传或粘贴给外部 AI 时，原文会离开本机，适用该服务商的隐私和保留政策。工作台不会代你判断是否适合分享，也不会保存跨文件的外发授权。

## 回复为何被拒绝

- **下载任务后修改过审校内容：** 旧回复已经过期。重新下载任务并重新分析，不要篡改版本号。拒绝旧回复是为了保护人工修改。
- **另一个项目、另一份原文或本机找不到任务：** 必须回到生成任务的项目。任务绑定项目、原文 SHA-256 和审校版本。恢复为新工程的备份不能复用旧任务，应重新下载。
- **缺少批次或对白、编号重复、证据不存在、姓名没有逐字依据：** 让 AI 按原任务重新生成。工作台使用本机保存的任务核实证据，不信任回复自带的锚点。
- **JSON 无法读取、字段或类型不正确：** 检查提示的行列或字段，只留下回复 JSON。不要上传下载的任务文件。不要把置信度写成带引号的字符串，也不要附加正文、确认状态或其他字段。
- **重复导入：** 同一任务只应用一次。重新分析请下载新任务。
- **超过 4 MB：** 回复只应包含标注，不要重复原文、任务或图片。

任一批次验证失败时，整个回复不会应用，审校版本也不会改变。可以修正回复后重新选择同一文件再试。有效回复只增加角色待审候选和未审对白的说话人建议；已确认、排除、合并及手工编辑的身份，和已经人工审校的对白，仍以人工记录为准。

本机生成的未完成任务可在应用重启后继续使用，前提是项目、原文和审校版本都未变化。任务记录不随可编辑工程备份迁移。

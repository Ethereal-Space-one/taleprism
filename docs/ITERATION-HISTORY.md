# Taleprism 迭代记录：从图版动效到随文演绎

这一页说明每版解决了什么，以及哪些行为**只属于当时的版本**。读者最容易注意到的变化是声音何时出现：0.7 要点听，0.8 可以在制作收尾时获得声音建议，0.9 才能在读到相应段落时自动响起。三者都不改写原文。

**版本身份。** 0.3.x 是此前的公开预览。下列 0.4.0、0.5.0、0.6.0、0.6.1、0.7.0、0.8.0 是未单独发布、未单独打 GitHub 标签的开发候选；记录它们不是补发六个版本。日期是开发记录日期，不是推算的公开发布日期。0.9.0 是已发布的 GitHub 公开预览；0.9.1 是后续的 GitHub 修订版。实际可下载的包以相应 Release 的附件和校验清单为准。已下载的读本携带当时的阅读器，不会因本仓库更新而改变行为。

## 0.4.0 · 让作者决定雨落在哪里（2026-11-17）

从内置示例走到作者自己的画：在插图上圈定可动区域，引用到这里已经读到的原句，比较静图和动态预览，再决定是否采用。雨线、接触点和涟漪对应作者标出的雨区与湿地；浪的接近、拍岸、飞沫与回撤跟随选定岸线，不用雾或移镜代替浪。草稿、明确指定的静图与复核通过的动效分开保存。

方向绑定原文指纹、图像内容与尺寸、以及插入位置。换图或挪动位置，不会自动继承旧复核。作者的预览门槛是八秒实际渲染，不是系统替作者判断构图合格。此时的读者仍需展开图后主动开启动效；系统要求减少动态时保留静图。

## 0.5.0 · 一篇原文配一幅画，就能交给读者（2026-11-18）

以前作者只想放一幅画，也容易走进完整镜头制作流程。这版让作者选原文、上传自己的图、接受底图、决定接在哪一段之后。不需要先设计角色、配音或动画；一幅静图已经可以交付。新导入的图会校正拍摄方向、处理色彩、保留透明度并剥离相机元数据，不重写旧图。动效预览不在可见区域时，不再累计复核时间。

独立阅读包完整解压后可以双击 `index.html`，不用先运行服务器；需要把旁边的素材文件夹一起保留。读本不等于可编辑备份。单幅图文制作的备份使用工程格式 v3，普通工程仍可使用 v2，旧 v1/v2 可导入。

## 0.6.0 · 让一段真正的朗读留在原句旁（2026-11-18）

段落朗读与人物对白不再混为一谈。作者选择一段文字、导入有权使用的录音、填写来源许可并完整试听，再决定采用。替换要重新审听；没有图也可以做成品。同一段已获许可的朗读用来检验无图和有图两种版式：没有插图的作品不必为一个空画框腾地方。

读者自己点「听这一段」，可以停止或隐藏朗读入口；缺音频时原文仍可读。读本只带已采用的录音和选定公开的署名。带朗读历史的工程备份用 v4，包含候选和制作资料，不宜当作读本分发。此处的朗读不是语音生成、录音身份鉴定或 WebGAL 对等功能。

## 0.6.1 · 修复引文与交付边界（2026-11-18）

诗中的空行也是文意。此版从规范化的 UTF-8 原文重建段间空白，让摘录在切换「原稿行式／舒展段落」后仍保留原来的间隔；过长摘录会提示分段，不静默截断。原始上传文件和既有段落、图版、朗读锚点不变。通用制作台也补上未保存修改提示、换源时的权利复核和失效朗读的撤下入口。

直接检查导出 ZIP，而非仅检查画面：阅读器只带渲染必需的已核准参数，不带导演观察或审校私注；可编辑包则保留制作事项和恢复线索。有实际编辑事项的工程可用 v5；旧工程没有记录覆盖范围时，恢复后明说「未知」，不会伪造终审通过。

## 0.7.0 · 为一个段落编一处声音，而不是为全书配乐（2026-11-18）

作者可以做十二秒的本机合成声景：细雨或风声、一辆按指定时刻驶过的车，或环境底声加这一次过车。采用前完整试听，声音与插图可以分别决定。读者在正文或对应插图旁**主动点听**，不循环、不连播、不带动翻页。合成素材不是现场录音。含声景历史的可编辑备份为 v6；有已采用声景的独立阅读数据为 v5，这两个版本号不是同一套编号。

《留门》只在第二段用细雨和一次过车，结尾雨停后不再铺声。旧示例的编排也不是全章铺声：《末班灯》的站台开场只配雨；《赤壁》只给「忽聽風聲響，旗旛轉動」所在段配风，另外六十六段不配。这项兼容验证不等于把新的示例读本或编辑档发布为 0.7.0 附件。

## 0.8.0 · 成稿后，作者可以再听一个意见（2026-11-18）

制作流程末尾加入默认收起的 **One More Thing**：分别考虑声音、影像或呈现方式，也可以三项都不采用。提案不是成品。音频要试听，底图要接受，动效须另行在画上划区并复核；回声折页只能引用前文原句，先试翻再采用。阅读或打开终审面板本身不触发模型调用。

三条路线分开标明：离线规则不是模型；调用已配置的兼容模型前需主动请求并确认本次发送的正文；外部结构化提案按原文指纹导入，来源不是身份认证。《留白处》使用逐项导入的 AI 创作提案，不是运行时模型接口实测。第三段留一幅静物，第五段可翻出第二段的一句话；末段的铅笔声在不到三秒后停止，在十二秒的声景内留下九秒多安静。另用不干预的对照检验了三个方向都建议不加的情况。未采用的理由和候选不会变成读者可见的效果。

## 0.9.0 · 在读到时出现，而不是让人四处找按钮（2026-11-18，本次预发布）

与 0.7/0.8 的手动点听、试翻不同，0.9 让作者**已经采用**的安排随阅读位置出现：读到声景段落时播放一次；读到插图时原位呈现，只有另行复核的局部动效才动；读到后段时展开回声原句，不跳回前文。两个只读演示有意不同：《留门》的雨声和过车落在第二段，右侧湿路可以微动；《留白处》的画始终不动，到了后段才出现回声与短促的铅笔声。没有安排的段落只是正文。

封面不播放。读者可选「安静阅读」保留手动入口，也可在正文暂停／继续自动演绎，或全局静音。浏览器挡住首次发声时，提示读者一次主动操作，不要求放宽浏览器设置。系统要求减少动态时仍为静图。段落**朗读**继续点播；人物**对白**仍按自己的设置，二者没有改成段落声景。阅读器不调用模型，不替作者新编效果，也不会强制翻页。

## 怎么判断这份历史的适用范围

- **原文、读本、工程是不同东西。** 原稿及字节锚点用于定位和复核；读本只应包含面向读者的文字与素材；工程备份可能包含未用素材、注释和审校历史。公开分享请选 Reader，而不是 Editable。
- **源码更新不会改写旧 ZIP，也不表示演示网站已同步。此次 0.9.0 发布时，GitHub Pages 仍是已部署的 0.3.2；此前的 0.3.3 GitHub 公开预览是另一回事。** 每个已交付独立读本使用自己打包的运行时。读者端与 WebGAL 的能力也不完全相同。
- **验收不是审美背书。** 历次复核用过实际独立包、离线 Chromium、原文与媒体校验和、恢复测试和动态效果设置。桌面浏览器中的手机宽度不是物理手机或 Safari 实测；完整播放也不等于真人听评、版权鉴定或艺术终审。

## 0.9.1 · 图在原处，声音也要在原句（2026-11-18，随后在 GitHub 发布）

0.9.0 的公开《赤壁》保住了江岸首图的浪、十二条图版画面描述以及两幅图等待诗句读完再出现的时机，但没有段落音轨；作者从示例工程另存读本时，也没能把十二条描述和两个延迟显示位置带过去。《末班灯》的首幅雨效还在，站台段落却没有雨声。文件校验通过，并不能证明一本书实际留下了哪种声音、图注和阅读时序。

本次分别恢复《赤壁》第十二段的一处风声、《末班灯》第二段的一处细雨，原文和已有图像动效不改。验收既检查四份阅读成品，也把两份工程导入空工作台，直接检查普通作者重导出的那本书。0.9.1 已发布后，原网址的《赤壁》也单独同步为同一版本；0.9.0 下载包未变。[版本说明与定位方法](RELEASE-v0.9.1.md)。

## 0.9.2 · 每幅审过，不等于每幅都要动（2026-11-18）

《留白处》那张静物画只有一幅。读者要看出旧历书托住了桌脚，翻动书页反而会带走注意力。0.9.2 把这个问题放回作者面前：对每幅放入正文的实图，看它出现前能读到的原句，记录为何留静、哪处值得动，或为什么现有手段做不好。未审不是留静；提出动效也不会启动播放。正式签核要完成逐幅判断，普通试读和工程备份不受此门槛限制。

四部示例共有 17 幅：12 幅留静，2 幅值得做但暂不支持，3 幅有原本就存在的动效。江岸浪能播放，但有一处盖住前景松枝，未修。和 0.9.1 相比，本版更新制作台、教程与提示模板；四个读本和两个可编辑示例的内容与 ZIP 字节都不变。[逐幅判断及理由](../examples/plate-screening/README.md) · [中英版本说明](RELEASE-v0.9.2.md)。

# 人物视觉导演标准

2026-11-05。回应人物插图未充分表现双方立场与心理的反馈。适用于后续人物对手戏、群像和现有插图修订；本轮先修订「帐中问疾」「华容相逢」两幅作为可比较样本。

## 先确定这一刻，再设计表情

每图先记录原文范围与具体瞬间，再分别写明各方的目标、所知、对对方的判断、公开姿态和未说出口的顾虑。原文明示的心理与艺术推断分开。人物不能预知后文，也不能在尚未作出决定时表现为已经决定。

把心理落实为看得见的行为：目光看谁、在观察什么反应；嘴唇与下颌如何维持或泄露情绪；手在控制什么、何处紧张；身体靠近、退让还是保持边界。每人选择两三个一致的信号，不堆叠夸张表情。保留人物主动应对局面的能力，不用固定的「忠勇」「奸诈」「睿智」脸谱替代即时反应。

## 镜头服务双方关系

需要看双方反应时，选择能同时读到两张脸的斜侧双人镜头；越肩镜头应有明确的主观视点，不能把另一方的表演藏没。人物权力可由位置、距离、姿态、空间阻挡和周围人的反应体现，不靠把强者画得巨大或一方打光成反派。群像按所知和处境分组，士兵、谋士和主将不应整齐复制同一种表情。

远景负责地理与阵势，近中景负责相互试探。大场面不要求每张脸都有特写，关键关系图则必须给神情足够面积。既有人物身份和画风延续，姿态、光线随情境改变。

## 验收

并排对照原文、旧图和新图。检查：这一刻是否准确；能否读出双方不同意图与回应对象；眼神、嘴、手、身体是否相互支持；身份是否延续；有没有提前揭示或添写情节；缩小后的主要关系是否仍成立。不以提示词写得详细代替成图达标。样图通过工具与人工目视自查后进入本机阅读预览，用户最终艺术审查仍待完成。

# Taleprism 使用与恢复

## 服务与数据

首次执行 `./start.sh`，以后执行 `./run.sh`；macOS 可用“打开Taleprism.command”后台启动，用“停止Taleprism.command”停止。后台日志在所选数据目录的 `workbench.log`，默认是 `data/workbench.log`。服务只监听本机，浏览器地址默认是 <http://127.0.0.1:8000>；电脑重启后需再次启动。

默认数据在 `data/`，可用 `STORYGAL_DATA_DIR` 指定另一个目录。端口从启动终端的 `STORYGAL_PORT` 读取。同一数据目录只能由一个工作台实例使用。旧原页启动脚本仍可使用。

## 作品与工程

- **可编辑工程 ZIP**：在制作台导入，创建新项目，保留原文、媒体、方案与作者制作检查；不继承接收者最终发布复核。
- **独立阅读器 ZIP**：解压后先 `python3 verify_package.py`，再 `python3 -m http.server 8080 --bind 127.0.0.1`，访问 <http://127.0.0.1:8080>。不需要制作台，但不能直接双击 HTML。
- **提示词入门 ZIP**：教程、原文和参考图，给自己的 AI 工具使用，不是工程导入包。

阅读进度保存在当前浏览器，工程迁移不携带个人进度。不要用成品阅读包替代可编辑工程备份。

## 常见恢复

| 现象 | 处理 |
| --- | --- |
| 浏览器打不开 | 确认服务已经启动、在同一台电脑、端口一致；检查后台日志 |
| 示例没有安装 | 从版本发布页下载可编辑工程，用“导入可编辑工程”打开；大型历史素材不随轻量源码提供 |
| 原文哈希不一致 | 保留现场，用可信原件新建项目或恢复完整备份；不自动改写原文 |
| 图片缺失或损坏 | 从可信文件重新上传并接受，回填方案；相关检查需要重做 |
| 上游修改后不能应用 | 重新确认方案，按叙事顺序检查当前及受影响的后续镜头 |
| 工程导入成功但提示待修复 | 原方案和素材状态已保留；按导入提示修复人物、图片或检查记录，再进行交付检查 |
| 旧连续性检查要求复核 | 新版需要完整原文与素材依据；保留旧记录，实际核对后重新记录检查，不直接修改哈希 |
| 复审发现已通过的镜头有问题 | 在该镜头连续性区域记录“不通过”或撤销原因；后续依赖镜头也需按顺序重新检查 |
| 更换对白说话人后音频未确认 | 原音频仍保留，原接受记录已撤销；按当前人物归属重新准备并试听确认 |
| 声音未接受或过期 | 试听接受；改读音、音色或表演要求后重新合成；暂不需要的对白取消选择 |
| 导出期间制作状态变化 | 保存后重新导出；旧成功成品保持原快照 |
| 退出时任务中断 | 重启后查看任务状态，重试未完成步骤；原文与已接受素材保留 |
| 停止后网页已断开，但仍提示退出中 | HTTP 端口关闭不等于后台任务退出；等待停止脚本确认进程结束且数据锁已释放，再复制数据目录。不要删除启动记录或锁文件强行“解锁” |
| 工程超过大小或记录限制 | 不删除素材来迁就导出；按下文停止服务后复制完整数据目录 |
| 工程导出提示缺失文件或恢复校验失败 | 保留完整数据目录，查看具体文件路径或结构问题；不要把缺媒体的 ZIP 当作成功备份 |
| 下载损坏或清单不匹配 | 重新下载或导出，不把损坏包作为交付物 |

## 备份

### 单个项目：可编辑工程 ZIP

制作台“示例与工程”可导出与导入工程。工程包含原文、人物与对白、制作方案、阅读编排和**全部已记录媒体**，包括旧候选、被拒绝素材和未选中的历史音频，不会静默跳过。它不是整机备份：不含模型密钥、模型缓存、工作日志、任务/成品导出历史或浏览器阅读进度。

导入与导出使用同一组限制：

- ZIP 文件本身最多 **160,000,000 字节（160MB）**，解压后所有文件总和也最多160MB；不是160MiB。
- 最多 **3000 个文件**，包括原文、JSON 清单与说明。
- `project.json` 和 `manifest.json` **各最多5,000,000字节**。
- 人物、对白、角色素材、阅读素材、音频、图解各表**最多5000条记录**。
- 图片必须是受支持的 PNG（最长边8192像素，最多2400万像素），音频必须通过 WAV 校验；不支持加密 ZIP 或未知工程版本。

导出前可检查文件总量、最大媒体与缺失路径。预检只看大小、数量和文件存在，不能替代完整校验；实际导出还校验哈希、媒体格式，并在临时隔离目录执行同一恢复流程，只有能够恢复的工程才提供 ZIP。导入始终新建项目，不覆盖现有项目。发布检查未通过的工程仍可恢复编辑，原状态保留并列出待修复问题。

大型历史工程可能因旧媒体累积而超过限制。当前没有“只保留当前素材”的裁剪备份模式，也不会自动清理或修改原工程。请改用完整数据目录备份。

### 完整本机状态：停止后复制数据目录

1. 确认实际数据目录：默认 `data/`，或启动环境／`.env` 中的 `STORYGAL_DATA_DIR`。停止时使用与启动相同的目录和端口配置。
2. 后台服务运行停止脚本，等到明确显示“**Taleprism 已停止，项目与作品保留。**”。脚本会等待原进程结束和数据锁释放，不会因网页断开就报成功。若显示仍在退出，保留启动记录并稍后重试；前台服务在原终端按 Control+C，等命令结束。
3. **复制**整个目录到新的备份位置，保留数据库、媒体、导出目录及可能存在的 SQLite 辅助文件，作为一组保存。不要移动或清空原目录，也不要只复制数据库。备份可能含原文与私人制作记录，应保存在可信位置。
4. 恢复前先给当前数据目录再做一份副本。将完整备份复制到一个新的恢复目录，用 `STORYGAL_DATA_DIR` 指向它启动；不要直接覆盖仍在使用的数据目录，不要同时运行两个写入实例。

### 验证备份能用

保留原工程不动，用一个**新的空数据目录**及空闲端口启动验证实例，例如：

```sh
STORYGAL_DATA_DIR="$HOME/Taleprism-restore-check" STORYGAL_PORT=18080 backend/.venv/bin/python tools/open_workbench.py --no-open
```

在 <http://127.0.0.1:18080> 导入刚导出的工程，确认原文、图片、声音、方案和阅读编排；做一次小编辑并保存，再导出、导入另一份新项目，确认可以继续创作。验证完整目录备份时，指向备份的**复制件**启动，不直接运行唯一备份。验证结束也需用相同配置停止，例如：

```sh
STORYGAL_DATA_DIR="$HOME/Taleprism-restore-check" STORYGAL_PORT=18080 backend/.venv/bin/python tools/open_workbench.py --stop
```

在新机器先安装应用，再导入工程或恢复数据目录。已有声音可播放；重新合成仍需实际可用的后端。模型密钥由新机器本地配置，不随项目迁移。

## 可选 AI 与声音

配置模板见 `.env.example`。保存配置、阅读、播放已接受声音和导出不会调用模型；主动执行 AI 操作才发送相关文本并可能产生费用。

本机合成需要 macOS 中文声音与 ffmpeg。云端 OpenAI 适配器的实际服务调用与声音品质尚未验证；没有账户时可先保存设置，不会生成声音。不提供真人音色克隆。生成后必须试听接受，程序校验不等于读音与表演正确。

# Taleprism 使用与恢复

## 服务与数据

首次执行 `./start.sh`，以后执行 `./run.sh`；macOS 可用“打开Taleprism.command”后台启动，用“停止Taleprism.command”停止。后台日志在 `data/workbench.log`。服务只监听本机，浏览器地址默认是 <http://127.0.0.1:8000>；电脑重启后需再次启动。

默认数据在 `data/`，可用 `STORYGAL_DATA_DIR` 指定另一个目录。端口从启动终端的 `STORYGAL_PORT` 读取。同一数据目录只能由一个工作台实例使用。旧原页启动脚本仍可使用。

## 作品与工程

- **可编辑工程 ZIP**：在制作台导入，创建新项目，保留原文、媒体、方案与作者制作检查；不继承接收者最终发布复核。
- **独立阅读器 ZIP**：解压后先 `python3 verify_package.py`，再 `python3 -m http.server 8080 --bind 127.0.0.1`，访问 <http://127.0.0.1:8080>。不需要制作台，但不能直接双击 HTML。
- **提示词入门 ZIP**：教程、原文和参考图，给自己的 AI 工具使用，不是工程导入包。

阅读进度保存在当前浏览器，工程迁移不携带个人进度。不要用成品阅读包替代可编辑工程备份。

## 常见恢复

| 现象 | 处理 |
| --- | --- |
| 浏览器打不开 | 确认服务已经启动、在同一台电脑、端口一致；检查后台日志 |
| 示例没有安装 | 从版本发布页下载可编辑工程，用“导入可编辑工程”打开；大型历史素材不随轻量源码提供 |
| 原文哈希不一致 | 保留现场，用可信原件新建项目或恢复完整备份；不自动改写原文 |
| 图片缺失或损坏 | 从可信文件重新上传并接受，回填方案；相关检查需要重做 |
| 上游修改后不能应用 | 重新确认方案，按叙事顺序检查当前及受影响的后续镜头 |
| 声音未接受或过期 | 试听接受；改读音、音色或表演要求后重新合成；暂不需要的对白取消选择 |
| 导出期间制作状态变化 | 保存后重新导出；旧成功成品保持原快照 |
| 退出时任务中断 | 重启后查看任务状态，重试未完成步骤；原文与已接受素材保留 |
| 下载损坏或清单不匹配 | 重新下载或导出，不把损坏包作为交付物 |

## 备份

单个项目优先使用可编辑工程导出。备份全部本机状态时，停止工作台后复制完整数据目录，数据库和媒体作为一组保存。恢复前先保留当前目录副本，再使用可信完整备份；不要单独覆盖数据库或同时运行两个写入实例。

在新机器先安装应用，再导入工程或恢复数据目录。已有声音可播放；重新合成仍需实际可用的后端。模型密钥由新机器本地配置，不随项目迁移。

## 可选 AI 与声音

配置模板见 `.env.example`。保存配置、阅读、播放已接受声音和导出不会调用模型；主动执行 AI 操作才发送相关文本并可能产生费用。

本机合成需要 macOS 中文声音与 ffmpeg。云端 OpenAI 适配器的实际服务调用与声音品质尚未验证；没有账户时可先保存设置，不会生成声音。不提供真人音色克隆。生成后必须试听接受，程序校验不等于读音与表演正确。

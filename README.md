# Taleprism

![书页上的文字化成江岸与一缕声波](docs/media/taleprism-cover.svg)

**保留小说原文，让插图、图解和声音在该出现的段落出现。** Taleprism 是一套 AI 创作模板、一座本地制作台，也是一种不用安装的读本。

## 从这里开始

| 你想做什么 | 第一步 |
| --- | --- |
| **用自己的小说** | [下载 AI 创作入门包](https://github.com/Ethereal-Space-one/taleprism/releases/download/v0.9.3/taleprism-agent-starter.zip)，不用先装制作台。 |
| **先看成品** | [在线读《赤壁》](https://ethereal-space-one.github.io/taleprism/)，不用下载。 |
| **编辑并导出读本** | [安装本地制作台](docs/快速上手.md)，可从自己的 TXT 或可编辑示例开始。 |

## 用自己的小说，先做一页

1. 解压入门包，只准备一章原文。用 Codex 或 Claude Code 打开解压后的目录；只支持上传的聊天工具，就交给它这一章和所需模板。
2. [复制给 Agent 的第一条指令](prompts/START-HERE.md#中文手顺)。让它先交 1–3 个带原文引文的镜头候选，不改写小说，也不急着生图。
3. 确认镜头后再出图。想分享成品时，将原文和成图放进制作台，挂到对应段落，导出独立读本。

## 读成品：从《赤壁》到《留门》

- **《赤壁》**：战区、阵营与事件脉络随阅读进度展开，不提前揭露局势。读到「旗旛轉動」，才有那一处风声。
- **《留门》**：卷门底下的一双黄靴不动，雨只落在右侧湿路，过车声也只在那一段出现。这是一个现代短篇，只提供读本。
- **《末班灯》**：适合跟着做一遍的三镜头练习，看人物、机位和道具怎么在相邻镜头里接得上。

[查看所有作品与下载](docs/DOWNLOADS.md)。可编辑作品只需下一个 ZIP：解压后打开 `Reader/index.html` 阅读，或把同包的 `Project.zip` 导入制作台继续制作。

## 做读本，不是给每段加效果

逐幅成图对照原句审查，留静也是选择。收尾可以让 AI 在声音、影像或呈现方式上提一个点子，作者决定是否采用。独立读本不调用 AI；读者可静音、暂停自动演绎或使用系统的减少动态效果。

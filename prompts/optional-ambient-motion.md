# 可选环境动效 / Optional ambient-motion authoring

先问「这个瞬间有什么力量，作用在哪里，读者因此多看懂什么」，再决定是否做动效。每镜头最多选一个主动作和一个可见后果；不需要动效的图直接沿用八模板。本文是可复制的**人工制作简报**，不是第九个必经模板、制作台导入字段或运行时协议。提交简报不等于已经渲染、检查或批准动效。

**原图始终完整可读。** 不用整图平移、缩放、晃动或全屏闪烁掩盖构图；可动层关闭、不可用或减少动效时回到原图。动效不推进剧情、不增加人物动作、不把后文风向、火光、入场或结局带到当前时刻。只有批准的当前镜头可以借此增强环境。

## 接到原有 03—08 / Connect the existing workflow

| 阶段 | 只在选择做动效时增加的工作 |
| --- | --- |
| [03 选镜](03-shot-plan.md) | 绑定逐字原文、位置与已批准瞬间；说明一个主动作、可见后果与阅读价值。没有合适作用边界就暂不做，不为了动效挤掉已批准镜头。 |
| [04 场景](04-scene.md) | 先审构图：主角、受力物、真实接触线、纵深和可动余地是否清楚；再登记像素锚点、保护区和四拍。未知几何不能冒充标定。 |
| [05 首图](05-first-image.md) | 新底图画中性或收势状态，静态也成立；不把浪峰、全部水滴轨迹或反复白沫烙在底图。 |
| [06 连续图](06-continuation.md) | 已有镜头先复用或局部修底图；保持人物、机位、道具状态与上一幅已检查图。新机位另做候选，不替换原定稿。 |
| [07 审片](07-review.md) | 对照实际原图和四拍帧，并看完整循环、窄屏裁切、减少动效和关闭状态；静图通过不能代替动效通过。 |
| [08 修复](08-repair.md) | 先区分是遮罩、节拍还是底图问题。只改失败项，保留原图与旧检查，再回查依赖镜头。 |

将下方记录作为 `ambient_effect` **人工简报**随现有输入传递：03 的工作表、04 的 `scene`／`shots`、05／06 的 `shot`／`continuity`、07 的 `expected`、08 的 `defect`／`preserve`。这里的字段名仅便于人与人交接，不改变任何模板的必填输入，不增加每镜头义务，也不要求写入 plan、manifest 或 runtime。不能假设制作台自动保存、读取或执行此记录。

## 记录与可复制 Prompt / Brief and copyable direction

先填写一份旁表；未选用时整份省略，不要给全章镜头批量补默认效果。

- **依据与身份**：原文文件、段落或精确位置、逐字引文、已批准的镜头／瞬间；把原文事实、批准的艺术选择、未知项分开。记录实际底图文件、素材 ID（如有）、SHA-256、实际上传的参考顺序与职责。拟用图、未观察图不能填成已检查。
- **主动作与读法**：力量从哪来，作用于什么，一个可见后果是什么；第一眼仍看谁，此刻不揭示什么。没有叙事价值可省略效果。
- **构图与静态回退**：主角、接触线、受力物与纵深可指认；保留留白与光源。写清关闭／不可用／减少动效时显示哪张原图。若底图长期喷白水或接触线不可辨，先提出局部重绘，未经选择不替换原定稿。
- **像素锚点**：查看实际底图后才填写 `source`（来向／起点）、`motionRegion`（允许运行区）、`collisionLine`（接触边界）、`protectedRegions`（人物、重要道具、文字与需稳定的灯光等）、可空的 `overshootRegion`（短暂越界区）。以原图左上为 `(0,0)`、右下为 `(1,1)`，注明原图尺寸与裁切映射；分别标记 `pixel_observed` 或 `pending_confirmation`，不把示意坐标当成实测。换图、裁切或新机位要重新核对。
- **四拍与因果**：`anticipation → contact → consequence → settle`。每拍写起止时间、方向、力度、衰减与共享事件／时钟；后果不能早于接触。次层弱于主层，留间歇，不同物理事件不必强行同步。
- **强度与证据**：设计基准、减少动效（优先原图）、关闭状态；标注当前仅是 `planned`、有实际 `rendered` 证据还是已 `inspected`。记录产物、时间帧、失败位置、检查者与未查项，不从简报文字推断通过。

### A. 静态图导演（随 04 → 05／06）

```text
以实际上传的原图／已批准构图为依据，为【精确原文与已批准瞬间】准备一幅静态底图。
观众第一眼看【人物／叙事线索】，第二眼才看【一个环境主动作的区域】。
清楚露出【真实接触边界】与【受力物】，以明暗和纵深分开，留出【允许动作的空间】。
保持【人物身份、姿态、道具状态、地标、机位、主光源】；禁止【此刻不能出现的后文元素】。
只画中性或收势一刻；不要把主动作峰值和全部轨迹烙进底图。关闭效果后图片仍完整。
先判断已有底图是否可复用。若边界不清，给最小局部重绘建议，不擅自替换已批准原图。
输出成图／局部编辑 prompt、禁止项、三条能在实际图上指认的构图检查。
此任务仅产生静态底图或文字建议，不声称已经生成动效。
```

### B. 环境动作导演（随 04 的人工旁表）

```text
先观察【实际底图文件及哈希】，不可从文件名猜图。绑定【原文引文、已批准瞬间及艺术选择】。
检查【主角、来向、接触边界、受力物、纵深、静态回退】；几何不足时先列局部修图建议。
按原图归一化坐标标定 source、motionRegion、collisionLine、protectedRegions、overshootRegion。
每个标记注明 pixel_observed 或 pending_confirmation；没有看图就不提供实测坐标。
只设计【一个主动作】及其后果，写 anticipation → contact → consequence → settle 四拍。
每拍写时间范围、方向、力度、衰减与事件：没有主事件时跟随层不得先出现。
同一次撞击的浪头、水花、白沫共享事件；次层减弱并留空档，不让所有层同时齐动。
给设计基准、减少动效和关闭方案；后两者优先保留原图，不用整图摇动／缩放／闪烁。
输出人工简报与所需验证证据，不写入未知 runtime 字段，不声称文字已经被渲染。
```

### C. 审片与最小修复（随 07 → 08）

```text
对照实际原图、预备、接触峰值、后果和收势帧，另外看完整循环与实际手机窄屏裁切。
先核人物／道具保护、接触边界、遮挡、后文禁区与静态回退，再核前因后果与水体／材质厚度。
主事件没发生时不准先喷白水；水花落尽后白沫可短暂存在并回流，不是同一条闪白线。
检查减少动效、关闭效果时原图是否稳定、完整；静图不证明时间顺序、循环或运行时行为。
逐项给实际位置、失败帧／时间和最小修改；没拿到帧、循环或关闭证据的范围写 not_checked。
给建议：通过 / 需修遮罩或节拍 / 需局部重画底图，同时保留各项状态与未解决问题。
若像纸面白线，先检查水体厚度、明暗和纵深，不直接加倍密度或亮度。
修复只改已观察缺陷；保留批准原图与历史检查，重新检查改动项及受影响的后续镜头。
```

## 例一：赤壁江岸 / Chibi river

**绑定而非改写**：[完整源码原文](https://github.com/Ethereal-Space-one/taleprism/blob/main/samples/sanguo-chibi/三國演義_第049-050回_赤壁.txt)第四十九回首段有「卻說周瑜立於山頂，觀望良久」。[既有方案](../examples/chibi/rebuild-v0.2.0.json)的 `river-overlook` 以回目后开篇预示安排「江岸望阵」：周瑜在右、舰队在左与远景。其位置与预示性质沿用原批准记录，不将本段引文伪装为该插入位置之前已经发生的事实。岸边浪是**批准的环境艺术演绎**，不是原文逐字水动力描述，也不借用后段东南风或火攻事实证明此刻有大风。

- **构图**：第一眼仍是右侧周瑜与远处舰阵。前景深色礁石须真实接水，水面与岩面有明暗和体积区分，江面保留长斜线。船灯、人物与山岸稳定；不加后文火光，不以浓雾遮接触线，不先画满白水。若实际底图无法指认接水线，只记录需局部修图，不臆造遮罩坐标。
- **锚点**：沿实际图上的斜岸标记 `collisionLine`，水侧是 `motionRegion`，岩脚上方只留一条窄 `overshootRegion`。人物、船只／船灯、地标与非接水岩壁为保护区。这里是设计说明，坐标仍须观察精确底图后标定，不能复用别图的遮罩。
- **关闭／减少动效**：显示同一张已批准静态原图，不冻结夸张浪峰；原图未修前保持原图，不偷偷覆盖成新候选。

以下时间只供设计起步，不是已渲染帧或水动力测量；四拍同属一次 `shore-hit` 事件。

| 四拍 | 设计时间 | 动作、方向与强度 |
| --- | --- | --- |
| anticipation／推近 | 0–1.8 秒 | 近处水体沿斜岸推近并抬起，有暗部厚度；远处仅弱小呼应，无撞岸水花。 |
| contact／撞岸 | 1.8–2.1 秒 | 触及实测岸线才触发 `shore-hit`；窄白水向上炸开，近处最强，绝不高过无关高岸。 |
| consequence／水花 | 2.1–2.8 秒 | 同事件水滴先散开再下坠；白沫留在岩脚，不在没有浪的别处独立喷发。 |
| settle／回流 | 2.8–4.8 秒 | 白沫向江里拖回并衰减；水花先消失，泡沫略留，末尾留白后下一浪，避免硬重置。 |

**QA 重点**：小屏能看见「抬水 → 碰岸 → 水滴下坠 → 泡沫回流」，而非明亮白线在岩上闪动；完整一轮没有人脸遮挡、悬空喷泉、穿岩或突然截断。检查未做就保持 `not_checked`，本例不为任何旧图或动效补写通过。

### 单独实验：贴水低机位插入镜头

若之后允许新增镜头，可另做 `river-low-angle-experiment` 候选：固定贴水机位、前景礁石与明确水线，浪从画外推入，撞击时暂遮远船倒影，落尽后船灯重现，再回原高岸全景。这里的「低」指机位贴近水面，**不是降低江面水位或改动原图地形**。人物不必跟着动。

它是独立实验，**不是已批准原镜头的替代品**。单独走 03 预算与位置、04 新视角空间／来源检查、05／06 候选制作和 07 审片；若无安全位置就不插入。未经创作者后来明确选择，不替换原图、挪动原位置或覆盖旧检查；没有产物不能声称实验已生成。

## 例二：末班灯更明显的雨 / Last Light, stronger rain

绑定 [P01 原文](../samples/last-light/source.txt)「傍晚的雨斜着落进站台」与既有 `arrival`／檐下初见瞬间；实际底图可用 `samples/last-light/arrival-v1.png`，先记录实际使用版本与哈希。**更明显的雨势是此镜头批准的艺术强度选择**，不是增加暴风、洪水或人物遇险，不因“强雨”改变他们的表演、灯的稳定性或长凳尺寸。

- 主动作是同一斜向雨线落向实际露天湿地，接触后只在可见湿地短促出涟漪。强度增加优先靠檐外雨线的可读大小、层次与对比，不整屏蒙白。不要凭空添加滴水檐槽或积水池。
- 先看檐线、遮挡和受雨地面；檐外为主区，入檐边界按实际图与原文局部保留。檐下人物、面部、手／布、测绘筒、长凳和主灯保护，雨不穿屋顶、不把干凳面当作水面。坐标仍待实际像素标定，赤壁岸线遮罩不能拿来套用。
- 每簇雨可错峰，**每次可见地面碰触的雨滴与涟漪**共享事件，不能让全场涟漪整齐齐闪。四拍为雨滴沿斜向进入有效区（anticipation）→触及该处湿地（contact）→小涟漪扩开（consequence）→涟漪衰减消失（settle）。没有相应碰触的位置不独立闪圈，人物与灯不随雨脉冲。
- 减少动效与关闭时优先回原图；不把所有动态雨轨迹烙进底图，也不把“关闭”误写成消除原图已经画出的静态雨。
- 到 P06「雨渐渐小了」必须重新按当前瞬间减弱或省略效果，不能把 P01 的较强雨势原样复制到 `recording`，也不能提前让小满、自行车或面包进入 P01。

**QA 重点**：对照原图与实际四拍／循环，雨只在允许受雨的区域，地面碰触先于涟漪，仍能辨认双方动作和旧灯；小屏不是一层白噪点。较强雨版、减少动效版和关闭版分别有证据才分别通过。此文不改变《末班灯》的历史图片、提示词或检查记录。

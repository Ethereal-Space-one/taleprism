## 从公开材料复建

复建输入是已发布的 [v0.1.0 赤壁独立阅读包](https://github.com/Ethereal-Space-one/taleprism/releases/download/v0.1.0/taleprism-v0.1.0-chibi-reader.zip)。制作方案和检查记录随源码提供。

输入 ZIP 的 SHA-256：

```text
b8597e51982dfc23acd10cdb99caf0e75cb616a599e4049ce9fb217a87adf84a
```

取得项目源码、安装依赖并构建阅读器后，将上述公开包下载到本机，执行：

```sh
uv sync --project backend --frozen
npm --prefix frontend ci
npm --prefix frontend run build
uv run --project backend python tools/build_chibi_demo.py \
  --source /path/to/taleprism-v0.1.0-chibi-reader.zip \
  --output .release/v0.3.1-chibi
```

脚本不联网、不生成图片、不调用配音服务。它在临时工作台中恢复公开内容，确认方案并重放已经完成的助手制作检查，然后在另一个空工作台中导入工程、再次导出阅读包。不会读取本机私有历史工程或修改用户 `data`。

输出：

- `taleprism-v0.3.1-chibi-project.zip`：可在制作台“导入工程”继续编辑；导入后获得独立的本地工程 ID。
- `taleprism-v0.3.1-chibi-reader.zip`：可独立托管的阅读器；先解压并运行 `python3 verify_package.py`，再以本地网页服务器打开。
- `chibi-demo-manifest.json`：两个附件的大小与校验值、输入来源、配方和检查记录校验值、重建结果。

原文、图片、角色 ID、正文锚点、55 段编排和地图保持一致。新生成的本地工程 ID、制作检查写入时间及导出 ID 可因运行而异，因此复建不承诺 ZIP 逐字节相同。比较复建结果应使用 manifest 和内容检查；发布附件自身各有固定 SHA-256。

脚本会先核对整个输入 ZIP、内部完整清单、原文与正文片段、所有27张图片和完整检查依赖。任一项改变即停止，不创建工程。修改配方或图片之后，必须实际重新检查；不能只重算哈希冒充检查。旧 `.release/chibi-demo` 和 `.release/v0.1.0` 目录受到写入保护。

## 制作方案与场景边界

可直接阅读 [重建配方](rebuild-v0.2.0.json)，通过制作台编辑导入后的方案。

| 物理场景 | 镜头 | 连续性处理 |
|---|---|---|
| 赤壁江面与曹军水寨 | 江岸望阵、火船待发、曹营观船、火起三江 | 共用舰队母版，记录火船待命→出发→接近→燃烧；不同阵营甲板与江面小舟分开记录；换机位的画外状态不等于消失 |
| 周瑜病榻 | 帐中问疾 | 病榻、床侧灯杯、帐柱与双方反应 |
| 南屏山七星坛 | 七星坛上 | 赤土坛、旗杆、香炉与执事群像 |
| 周瑜议事帐口 | 风先入帐 | 桌面、灯焰、竹简、帐帘与风向，不混入病榻 |
| 接应船与追船 | 子龙断索 | 两条船、追船篷索、赵云弓箭 |
| 夏口授计军帐 | 军帐授计 | 案、部署木块、香炉、出口与诸将位置 |
| 乌林西侧山路 | 败军入山 | 泥道、路边树竹、后军辎重和疲马 |
| 葫芦谷口 | 谷口翼德 | 狭路、长矛、两军战马和阻击阵位 |
| 华容道 | 华容相逢 | 泥道、关羽长刀、双方坐骑，尚未放行 |

这9个制作场景与阅读器原有的10个章节环境段是不同概念：前者约束图像制作与物件连续性，后者控制55段阅读呈现。通用军帐、树林背景仍用于氛围呈现，不能拿背景复用证明不同地点具有同一套家具或道路。

## 视觉检查与创作者边界

[visual-review-v0.2.0.json](visual-review-v0.2.0.json) 记录了2026年11月12日逐图检查：12幅情境图、9张立绘、6张背景／封面，每项都有图片哈希与具体观察；还绑定原文、阅读数据和配方哈希。没有重新生成或修改旧图。

人物心理表达重点核对了孔明从容与周瑜惊疑、黄盖知情与曹操自得、张飞威慑与曹军惊惧、曹操求情与关羽守令。检查保留以下局限：祭坛旗数、执事服色与鞋履未做逐项原文复原；授计群像与断索升帆压缩了相邻动作；通用背景不提供精确空间连续性；地图只用于约略阅读辅助。

构建生成的检查署名为 `assistant`，每项引用此记录哈希。最终创作者美术复核始终为 `pending`，不会自动写入最终交付复核。历史 [demo-review.json](demo-review.json) 原样保留。

公开工程的检查说明和 README 包含检查来源；阅读包 `storygal-source/` 内保存新配方、新检查及原有素材来源文件。

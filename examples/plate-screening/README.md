**同是水，不是同一个决定。** 《赤壁》开篇有清楚的岩石接水边界，浪撞上去再退，人物与船灯都不必动。**播放证实，遮挡尚未合格：**对照原图与真实合成帧，旧波浪层有一处压在前景松枝上。本版不改图、不改浪层；即使检测到播放，也不能把这处遮挡当作通过。「曹营观船」那段虽然明写波浪，图却是从船上看开阔江面，没有近岸接触线，不能借用开篇配方。「败军入山」画了湿泥，但真正写大雨的句子在这张图之后，不能用后一句替当前镜头添雨。

**有机会，仍可以暂不做。** 东风转向时，帐帘和布尾很能说明受力方向；火场中的水面反光也值得局部试验。现有雨线及江岸波浪都不能表现布料受风、火光在水上移动。这两条记在待支持栏，画上没有因此出现动效，原有东风声景也不是布料动画的证据。

**静止不是漏审。** 《末班灯》第二幅的关键是指向图纸的手和听到问题后停住的人，不能因第一幅画了雨就再上一遍。《留白处》让读者自己看出两册旧历书托住了缺腿那一角；若将书页掀起或让光影加速掠过桌面，就替这段文字作了另一种时间安排。

这些文件保存选择和理由，不保存它们自己的「已生效」认证。其余段落的声音、折页和原文位置未被复审改动。查看[流程与复验方式](../../docs/PLATE-SCREENING.md)。本版四份阅读包与此前读本字节相同；最初复审使用的四个输入是 [v0.9.1 公开发行](https://github.com/Ethereal-Space-one/taleprism/releases/tag/v0.9.1)的读本；本版的文件名、ZIP 摘要和工作表在[目录](catalog.json)里。
